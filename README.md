# Getting Started GitHub-App

### Для запуска приложения, выполните следующие действия:

***Откройте терминал и клонируйте проект в нужную вам директорию:***

`git clone https://github.com/Murzaliev-Azamat/github-app.git`

***Затем перейдите в папку проекта:***

`cd github-app`

***Установите зависимости:***

`npm install` (Node.js version v19.9.0)

***Запустите приложение, командой:***

`npm run start`

***Зайдите на сайт https://cors-anywhere.herokuapp.com/corsdemo и нажмите на кнопку (для обхода CORS политики GitHub):***

`Request temporary access to the demo server`
